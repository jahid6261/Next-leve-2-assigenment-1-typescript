

# TypeScript Assignment

## Overview

This repository contains my solutions for the **Problem Solving with TypeScript & OOP** assignment.

The assignment focuses on TypeScript fundamentals, functions, type safety, generics, interfaces, classes, inheritance, and asynchronous programming.

## Project Structure

```text

├── solutions.ts

```

## Solutions

The `solutions.ts` file contains TypeScript problem-solving exercises covering:

- Functions and optional parameters
- Union types and type narrowing
- Readonly tuples
- Generic functions
- Interfaces and array methods
- Classes, inheritance, and access modifiers
- Promises and asynchronous operations
